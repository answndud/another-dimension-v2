# ADR 0001: 로컬 웹 UI와 루프백 HTTP 서버

- 상태: 채택
- 관련: [architecture.md](../architecture.md) 2절

## 맥락

중앙 서버 없이 파일 접근과 프로세스 수명을 직접 다뤄야 하고, 화면은 설치 없이 쓸 수 있어야 합니다. 브라우저만으로는 암호화 파일을 안정적으로 보관하기 어렵습니다.

## 결정

Rust 프로그램이 `127.0.0.1`의 임의 포트에서 정적 UI와 API를 제공하고, 사용자는 Chromium 계열 브라우저로 접속합니다. 다른 웹사이트의 호출을 막기 위해 다음을 모두 적용합니다.

- 정확한 `Host` 비교(DNS rebinding), 정확한 `Origin`과 고정 `Content-Type`(CSRF)
- 터미널에 출력되는 256비트 일회용 연결 코드로 세션 토큰 발급, 이후 Bearer 인증
- 토큰은 쿠키가 아닌 `sessionStorage`에 보관
- 엄격한 CSP, CORS 헤더 없음, 정적 파일은 바이너리에 내장

## 대안

- 브라우저 전용 정적 앱: 파일 보관과 수명 제어가 어렵습니다.
- Electron 등 데스크톱 셸: 의존성과 공격 표면이 커집니다.

## 결과

- 같은 사용자 권한의 악성 프로그램은 막지 못합니다. 브라우저·확장 프로그램이 침해되어도 마찬가지입니다.
- 직접 만든 HTTP 파서를 유지해야 합니다. 현재 요청 deadline과 동시 처리가 없다는 한계가 [SECURITY.md](../../SECURITY.md#known-weaknesses)에 기록되어 있습니다.
