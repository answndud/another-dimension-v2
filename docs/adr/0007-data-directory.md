# ADR 0007: 데이터 위치와 빌드 종류

- 상태: 채택
- 관련: [SF-008](../security-fixes.md)

## 맥락

릴리스 빌드가 빌드한 기기의 소스 트리 경로(`CARGO_MANIFEST_DIR`)에 데이터를 저장했습니다. 바이너리를 다른 기기로 옮기면 그 경로가 없거나 다른 사용자의 것입니다.

## 결정

1. 디버그 빌드는 저장소의 `chat-data/`, 릴리스 빌드는 사용자별 `~/Library/Application Support/Another Dimension v2/`를 씁니다.
2. `ANOTHER_DIMENSION_DATA_DIR`이 모든 빌드에서 위치를 덮어쓰되, 절대 경로이고 `..`와 심볼릭 링크가 없으며, 이미 있다면 내 소유이고 그룹·타인 접근이 불가능(`chmod 700`)한 디렉터리만 받습니다. 맞지 않으면 **권한을 바꾸지 않고** 거부합니다. 공유 디렉터리의 권한을 조용히 바꾸면 사용자를 자기 폴더에서 막을 수 있기 때문입니다.
3. 시작할 때 저장 위치를 터미널에 표시합니다. 옛 위치(소스 트리의 `chat-data/`)에 데이터가 남아 있으면 경고하고, 자동으로 옮기지 않습니다.

## 근거

빌드한 기기에 의존하는 경로는 비밀을 둘 곳으로 부적절합니다. 위치를 보여 주면 사용자가 자기 데이터가 어디 있는지 알 수 있습니다.

## 대안

- 항상 소스 트리: 설치된 바이너리에서 의미가 없습니다.
- 자동 이전: 사용자 데이터를 조용히 옮기는 것은 위험해서 경고만 합니다.

## 결과

**기존 `chat-data/`를 `cargo run --release`가 더 이상 읽지 않습니다.** 사용자가 직접 옮겨야 합니다. 이 결정은 사용자에게 확인받지 않고 정했습니다(PLAN.md 기록).
