# 프런트엔드 구조

프레임워크 없이 HTML·CSS·JavaScript만 사용합니다. 외부 폰트, CDN, 분석 도구는 쓰지 않으며, 정적 파일은 Rust 바이너리에 `include_bytes!`로 내장되어 로컬 서버가 제공합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `web/index.html` | 마크업과 CSS(`<style>`). 라이트/다크 테마 토큰은 `:root`, `:root[data-theme="dark"]`에 있습니다. |
| `web/app.js` | 화면 전환, API 호출, 채팅·기록·백업 상태 관리 |
| `web/reprotect-work.js` | 비동기 재보호 작업의 세대 번호를 추적해 오래된 완료가 화면 상태를 덮어쓰지 못하게 합니다. DOM에 접근하지 않습니다. |
| `web/reprotect-ui.test.cjs` | Node VM 기반 프런트엔드 테스트 (`node --test web/reprotect-ui.test.cjs`) |

## 화면 구성

- **헤더 메뉴**: 화면 설정(테마)과 관리 화면 이동, 계정 동작을 그룹으로 나눈 패널입니다. 바깥 클릭, Escape, 화면 전환 시 닫힙니다.
- **관리 다이얼로그**: 연결 설정, 신원 관리, 대화 기록 관리를 하나의 네이티브 `<dialog>`에서 보여 주며 선택한 패널만 표시합니다. 다른 화면으로 이동하면 닫혀 숨겨진 화면에 모달이 남지 않습니다.
- **대시보드**: 새 대화 생성과 초대 코드 참여 카드로 구성됩니다.
- **채팅 화면**: 헤더(제목·연결 상태·기록 확인·연결 종료), 상태 영역(전송/저장 상태, 신원·기록 복원 절차), 스크롤되는 메시지 목록, 하단 입력 폼. 상대 메시지는 왼쪽, 내 메시지는 오른쪽, 시스템 메시지는 가운데에 놓입니다.
- **대화 기록 관리**: 대화 정보, 기록 탐색(현재 페이지 범위 검색), 백업/복원, 삭제/보관 순서입니다. 백업과 삭제 영역은 기본 접힘 상태의 `<details>`이며 DOM을 유지해 접기만으로 입력이나 진행 중 작업이 초기화되지 않습니다.

## 설계 원칙

- **안전한 렌더링**: `innerHTML`, `eval` 등 HTML 문자열 삽입 경로를 쓰지 않습니다. 메시지 본문의 링크는 `appendMessageBody`에서 안전하게 처리하며, 외부 링크를 열 때 Tor 사용 여부를 확인합니다.
- **인증 토큰 보관**: 로컬 세션 토큰은 `sessionStorage`에만 두며 쿠키를 쓰지 않습니다.
- **스크롤 정책**: 새 메시지가 올 때 사용자가 최하단 80px 이내에 있을 때만 따라갑니다. 과거 기록을 읽는 중에는 위치를 유지합니다.
- **비동기 경합 방어**: 대화별 초안과 전송을 대화 단위로 분리하고, 늦게 도착한 응답이 새 대화나 새 화면 상태를 갱신하지 못하게 소유권을 검사합니다. 전송 오류, 전송 상태, 저장 상태는 서로 독립된 영역으로 두어 연결 폴링이 오류 표시를 지우지 않습니다.
- **접근성**: `aria-live` 영역과 레이블을 유지하고, 모든 버튼을 키보드로 조작할 수 있으며, 연결 단계가 바뀔 때만 포커스를 이동합니다. 상태는 색상만으로 전달하지 않고 텍스트를 함께 씁니다. `prefers-reduced-motion`을 지킵니다.
- **디자인 토큰**: 라이트/다크 Slate 팔레트, 4px 단위 간격, 44px 기본 조작 높이, 입력·버튼 8px, 카드·다이얼로그 12px 반경을 사용합니다.

## 검증 범위와 한계

- 자동 테스트는 전송 경합, 초안 처리, 연결 단계, 오류 표시, 기록 화면 구조 등을 다룹니다.
- 실제 브라우저에서의 시각적 균형, 좁은 창 레이아웃, 보조기기(스크린 리더) 낭독, 네이티브 다이얼로그의 Escape 동작은 자동으로 검증하지 않았습니다.
- 지원 대상은 Apple Silicon macOS의 데스크톱 Chromium 계열 브라우저입니다.
