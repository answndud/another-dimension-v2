대화 기록

현재는 양쪽에서 다시 연결을 선택해야 합니다.

상대 확인 백업은 이 개인 접속 코드로 보호됩니다. 대화 내용 백업과 별도로 저장하세요. 오래된 백업의 최신 여부는 확인할 수 없습니다.

새 백업은 개인 접속 코드에서 만든 키로 암호화합니다. 비밀번호를 설정하면 코드와 비밀번호가 모두 있어야 복호화할 수 있고, 둘 중 하나라도 잃으면 복구할 수 없습니다. 비밀번호를 비우면 코드만 사용합니다. 이전 ADBACK2는 암호화 키를 백업 비밀번호로 만들지만 파일 인증은 이전 신원 공개키에도 묶여 있어 이전 코드가 필요합니다. 새 보호는 이전 파일에 소급 적용되지 않습니다.

이전 신원 백업 재보호

이전 신원 코드와 필요한 백업 비밀번호로 파일을 복호화해 현재 신원용 새 파일을 만듭니다. 새 파일을 저장 위치에서 다시 읽어 확인하기 전까지 원본은 보존됩니다. 확인 후 원본 삭제는 사용자가 직접 선택하고 Finder에서 처리합니다.
