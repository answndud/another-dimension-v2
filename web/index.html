기존 코드 관련 안내

기존 백업도 그대로 열 수 있습니다. 이 기능은 유출된 코드를 무효화하지 않습니다. 서버 없이 기존 코드의 복사본을 폐기할 수 없으므로 이전 코드는 계속 유효하며, 이전 코드를 가진 사람도 이 신원에 로그인할 수 있습니다.

새 신원으로 교체

교체 전 확인 사항

현재 기기의 대화 기록과 확인된 상대 정보를 새 신원 키로 복사합니다. 새 초대에서 상대와 지문을 다시 비교한 뒤, 상대 기기에 일치하는 이전 확인 기록이 있으면 상대가 직접 선택해 기존 대화를 연결할 수 있습니다. 이전 신원 ID 주장은 동일 인물의 증명이 아니므로 별도 연락 수단으로 새 지문을 확인하세요. 다른 기기와 기존 백업은 바뀌지 않으며 이전 코드는 계속 유효합니다.

새 신원으로 교체할까요?

현재 기기의 기록과 확인 상대 정보를 새 코드로 복사합니다. 새 코드를 저장하고 각 상대와 새 초대·지문을 별도 연락 수단으로 다시 비교해야 합니다. 일치하는 이전 대화를 상대가 선택해 연결해야 기록이 이어집니다. 다른 기기와 백업은 바뀌지 않으며, 이전 코드는 계속 유효합니다.

암호화 백업

새 백업은 개인 접속 코드에서 만든 키로 암호화합니다. 비밀번호는 선택 사항입니다. 설정하면 코드와 비밀번호가 모두 있어야 복호화할 수 있고, 둘 중 하나라도 잃으면 복구할 수 없습니다. 비밀번호를 비우면 코드만 사용합니다. 이전 ADBACK2는 암호화 키를 백업 비밀번호로 만들지만 파일 인증은 이전 신원 공개키에도 묶여 있어 이전 코드가 필요합니다. 새 보호는 이전 파일에 소급 적용되지 않습니다.

상대방 신원 정보 백업

상대방 신원 정보 백업은 이 개인 접속 코드로 보호됩니다. 대화 내용 백업과 별도로 저장하세요. 오래된 백업의 최신 여부는 확인할 수 없습니다.
