# another-dimension-v2

## 실행

일반 연결은 다음 명령으로 시작합니다.

```sh
cargo run --release
```

Tor 연결은 사용자가 Tor SOCKS 서비스를 먼저 실행한 뒤, 해당 로컬 주소를 지정해 시작합니다.

```sh
cargo run --release -- --tor-socks 127.0.0.1:9050
```

환경에 따라 Tor SOCKS 포트가 다를 수 있습니다. `127.0.0.1:9050` 대신 사용 중인 Tor의 로컬 주소와 포트를 입력하세요. Tor 모드에서는 relay 연결이 지정한 로컬 SOCKS5 프록시를 통해서만 이루어집니다. 프록시 연결이 실패하면 직접 연결로 전환하지 않습니다.

현재 프로그램은 Tor를 자동 설치하거나 실행하지 않습니다. Tor Browser, Tor 서비스 등 사용자가 신뢰하는 Tor SOCKS 서비스를 먼저 시작해야 합니다. 앱 화면에는 시작 모드가 표시되지만 해당 SOCKS 서비스가 실제 Tor인지는 확인하지 않습니다. 실제 relay 연결과 Tor 누출 여부는 사용자의 수동 검증이 필요하며, Tor 사용만으로 완전한 익명성을 보장하지 않습니다.
