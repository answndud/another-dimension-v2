# another-dimension-v2

## 실행

일반 연결은 다음 명령으로 시작합니다.

```sh
cargo run --release
```

Tor 연결은 신원 로그인 후 `연결 및 알림 설정`에서 `Tor SOCKS 연결`을 선택하고 로컬 주소를 저장합니다. 변경 후에는 터미널에서 프로그램을 종료하고 같은 실행 명령으로 다시 시작하세요. 저장한 모드는 다음 실행에도 적용됩니다.

사용 중인 Tor SOCKS 주소를 입력합니다. 기본 예시는 `127.0.0.1:9050`이며 Tor Browser 등의 설정에 따라 `127.0.0.1:9150`일 수 있습니다. 프로그램은 Tor를 자동 설치하거나 실행하지 않으므로 Tor 서비스를 먼저 시작해야 합니다. relay 연결은 설정한 SOCKS5 프록시만 사용하며, 프록시 연결이 실패하면 직접 연결로 전환하지 않습니다.

메시지 알림은 같은 설정에서 선택할 수 있고 알림에는 본문이나 상대 ID가 표시되지 않습니다. macOS 알림 권한이 필요합니다. 앱은 SOCKS 서비스가 실제 Tor인지 확인하지 않으며, Tor 사용으로 완전한 익명성을 보장하지 않습니다.
